# StudaFly Mobile

> Application mobile pour StudaFly - Prepare ton depart a l etranger, sereinement.

![CI](https://github.com/StudaFly/Mobile/actions/workflows/ci.yml/badge.svg)

## Quick Start

```bash
# Installer les dependances
pnpm install

# Lancer en dev
pnpm start
```

## Scripts

| Commande | Description |
|----------|-------------|
| `pnpm start` | Lance Expo |
| `pnpm ios` | Lance sur iOS |
| `pnpm android` | Lance sur Android |
| `pnpm lint` | Verifie le code avec ESLint |
| `pnpm typecheck` | Verifie les types TypeScript |
| `pnpm test` | Lance les tests |
| `pnpm test:coverage` | Tests avec couverture |

## Stack

- React Native
- Expo SDK 50
- TypeScript
- Jest + Testing Library
